# เงินของฉัน

เว็บแอปส่วนตัว (PWA) สำหรับจดรายจ่ายและหนี้ที่ผ่อนเป็นงวด ติดตั้งลงหน้าจอโฮม iPhone ได้ ใช้ออฟไลน์ได้

- **ข้อมูลอยู่ในเครื่องเท่านั้น** (localStorage ของเบราว์เซอร์) ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชีผู้ใช้ — repo นี้มีแค่โค้ด
- รายจ่าย: จำนวนเงิน หมวด วันที่ บันทึก + สรุปรายเดือนแยกหมวด
- หนี้ผ่อน: ยอดหนี้ทั้งหมด จำนวนงวด วันครบกำหนดงวดถัดไป → แอปคำนวณยอดต่องวด (เศษไปรวมงวดสุดท้าย) ยอดคงเหลือ แจ้ง "ใกล้ครบ/เลยกำหนด" บนหน้าแรก
- เตือนด้วยปฏิทิน iPhone: ปุ่ม "เพิ่มลงปฏิทิน" สร้างไฟล์ .ics (ทุกงวดที่เหลือ เตือน 09:00 วันก่อนและวันครบกำหนด)
- สำรอง/กู้คืนเป็นไฟล์ .json (เก็บใน iCloud Drive) และส่งออกรายจ่ายเป็น CSV

ไฟล์: `index.html`, `app.css`, `app.js`, `sw.js` (แคชไฟล์แอปไว้ใช้ออฟไลน์), `manifest.webmanifest`, `icons/`
แก้ไฟล์ใดแล้วให้เพิ่มเลข `?v=` ใน index.html และ `VERSION`/รายการไฟล์ใน sw.js ให้ตรงกัน เพื่อให้มือถือโหลดของใหม่
